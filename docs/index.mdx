面向组件时代的\
**Markdown**
=================

MDX 让你可以在 Markdown 内容中使用 JSX。
你可以导入组件，例如交互式图表或提示框，并将它们嵌入到内容中。
这让使用组件编写长篇内容变得非常轻松。 {/* more */}
🚀

## MDX 能做什么？

<div className="big-columns">
  <div>
    你可以通过 JSX 在 Markdown 中嵌入组件：

    ```mdx path="example.mdx"
    import {Chart} from './snowfall.js'
    export const year = 2023

    # 去年的降雪量

    在 {year} 年，降雪量高于平均水平。
    随后迎来了温暖的春天，导致附近许多河流
    出现了洪水泛滥的情况。

    <Chart color="#fcb32c" year={year} />
    ```
  </div>

  <div>

## MDX 简述

<div className="emoji-list">
  * ❤️ **功能强大**：MDX 融合了 Markdown 和 JSX 语法，完美适配
    基于 JSX 的项目
  * 💻 **一切皆组件**：在 MDX 中使用已有组件，也可以将其他 MDX 文件
    作为组件导入
  * 🔧 **高度可定制**：可以决定每种 Markdown 结构渲染为哪个组件
    （`{h1: MyHeading}`）
  * 📚 **基于 Markdown**：保留了 Markdown 的简洁与优雅，
    只在需要时才使用 JSX
  * 🔥 **极速 blazing fast**：MDX 没有运行时，所有编译都在构建阶段完成
</div>
