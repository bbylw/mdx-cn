# GitHub 风味 Markdown（GFM）

本指南探讨了如何支持 GFM 特性，如自动链接字面量、
脚注、删除线、表格和任务列表。 {/* more */}
MDX 支持标准 Markdown 语法（[CommonMark][]）。
这意味着 [GitHub 风味 Markdown（GFM）][gfm] 扩展默认不受
支持。
它们可以通过 remark 插件 [`remark-gfm`][remark-gfm] 来启用。
该插件与所有 remark 插件一样，可以在 [`ProcessorOptions` 中的 `remarkPlugins`][processor-options] 中传递。
有关插件的更多信息请参见[§ 扩展 MDX][extend]

假设我们有这样一个 MDX 文件：

```mdx path="example.mdx"
# GFM

## 自动链接字面量

www.example.com, https://example.com, and contact@example.com.

## 脚注

一个注释[^1]

[^1]: 大注释。

## 删除线

~一个~ 或 ~~两个~~ 波浪号。

## 表格

| a | b  |  c |  d  |
| - | :- | -: | :-: |

## 任务列表

* [ ] 待办
* [x] 已完成
```

上面的带 GFM 的 MDX 可以用以下模块转换：

```js twoslash path="example.js"
// @filename: example.js
/// <reference types="node" />
// ---cut---
import fs from 'node:fs/promises'
import {compile} from '@mdx-js/mdx'
import remarkGfm from 'remark-gfm'

console.log(
  String(
    await compile(await fs.readFile('example.mdx'), {remarkPlugins: [remarkGfm]})
  )
)
```
